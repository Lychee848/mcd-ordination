你说你是麦门信徒。
那你的教义，写下来了吗？

把「麦当劳用户行为」当作 prompt，产出两样东西：一套只属于你的麦门卡证， 和一枚能真的写进订单备注的麦门暗号。 不代下单、不支付、不碰账号——它只负责把已经做过的那些事，变成一句能说出口的话。

先看一张卡 → 30 秒跑起来
同一份代码、同一套板式：深圳的夜祷老客 / 成都的跨城巡礼者 / 哈尔滨刚入门的新客。
01

现场试：换个人，卡和暗号都变

下面是三份合成人设的真实输出（离线生成，不调用任何接口）。切换人设、卡种、暗号体裁看看。

这是 L2 成品卡（共享底图 + 每人不同的构图变体）。 零依赖的 L0 纯 SVG 版见 l0_card.svg（6 KB，无位图）。

02

两件产出，其实是一件事

卡负责被看见，暗号负责被回应。没有暗号，卡只是好看的截图；没有卡，暗号没有来历。

OUTPUT 01

卡证 · 四种信息结构

人物卡答「他有多强」，食物卡答「这是什么」（六维取自官方营养表，一克不编）， 行为卡答「什么时候能做一次什么」，地点卡答「这个地方长什么样」。 板式一致所以像一套，画派/框色/星级不同所以不是同一个人。

OUTPUT 02

暗号 · 三种体裁

问候什么都不求；请求是一句一本正经的玩笑，店员照做是彩蛋、不照做也成立； 接龙留半句话给店员，下次你带着他写的那句再来，就是第二章。 勾选后可挂进订单备注。

03

四步闭环

每一步都只用官方 MCP 能拿到的东西，不猜、不编、不假装写入。

STEP 01

拉行为

订单、账户、券、抽奖、在售菜单。频次、时辰、门店、单品偏好。

STEP 02

归纳

九阶品秩（四项加权百分位）+ 教义摘录（七典归组，互斥不共存）。金额不进公式。

STEP 03

编译

四版式卡 + 八槽位暗号。同一份行为向量，所以卡上的数字和暗号里的说法永远对得上。

STEP 04

用出去

勾选写进备注（能力探测：有字段就写，没有就给你可复制文本），店员回应 → 回报 → 下一章。

04

九阶：把百分位翻译成身份

不是排行榜。卡面永远不印百分位数字，只印品秩名——它描述你的修持轨迹，不给你发成绩单。

百分位品秩拉丁光环
≥ 99.5%麦门在世Summus Maimen全幅圣光 + 彩窗
97 – 99.5%枢机主教Cardinalis红金环 + 放射线
90 – 97%主教Episcopus金环 + 多重同心环
80 – 90%司铎Presbyter完整金环 + 细射线
65 – 80%执事Diaconus分段金环
50 – 65%传道员Praedicator分段金环
25 – 50%门徒Discipulus细金线圈
10 – 25%望教者Catechumenus仅一道细弧
< 10%慕道者Auditor无

加权：频次 0.40 / 门店 0.25 / 纯度 0.20 / 夜祷 0.15。客单价、累计金额、券使用率均不进公式。

05

抽卡：硬币是真实交易，而且能验算

一单一抽，与金额无关；结果由 hash(订单号 + 用户盐 + 版本) 决定，任何人拿同一份数据都能复算出同一张卡。

概率只看「这一单有多特别」

凌晨 3–5 点 +3、跨城 +2、开业/新品首日 +4、生日 +4。连续 12 抽没出金闪，第 13 抽权重翻倍。

卡面印 V XXXXX

这串码由卡面 7 项公开量算出。你可以编一句更酷的暗号，但编不出能对上卡面的短码。

扫光只合成在画面窗内，文字与数值一点不受影响。
06

30 秒跑起来

不需要 MCP Token、不需要 API Key、不需要联网。仓库自带三份人设数据。

# 只装本包，不带任何第三方依赖 git clone <repo> && cd mcd-ordination pip install -e . # 一次出全套卡 + 暗号 python -m mcd_ordination demo # 只出暗号（问候 / 请求 / 接龙） python -m mcd_ordination sign --kind story # 挂进订单备注：有字段就写，没有就给你可复制文本 python -m mcd_ordination order --kind ask

不装 Pillow 也能跑：L0 是纯 SVG，一张卡 6 KB，全是矢量，任何浏览器直接打开。
